# Amazon Sales Analytics Project

## Project Overview

This project analyzes Amazon sales transactions using MySQL and Power BI to uncover insights into revenue performance, product demand, fulfillment efficiency, and regional sales distribution.

The analysis focuses on transforming raw sales data into actionable business insights through SQL-based exploration, KPI development, and interactive dashboard reporting.

## Tools & Technologies

* MySQL
* Power BI
* Excel

## Key Business Metrics

* Total Revenue
* Total Orders
* Total Quantity Sold
* Average Order Value (AOV)

## Analysis Performed

* Data Exploration & Validation
* Missing Value Assessment
* Revenue Analysis by Category
* State-wise Sales Performance
* Fulfillment Channel Analysis
* Monthly Revenue Trend Analysis
* Top Performing Products (SKU Analysis)
* Above-Average Sales Identification using Subqueries
* Product Revenue Ranking using Window Functions

## SQL Skills Demonstrated

* Aggregate Functions
* GROUP BY & HAVING
* CASE Statements
* Subqueries
* Window Functions (RANK)
* Date Functions
* Business KPI Calculations

## Dashboard Highlights

The Power BI dashboard provides interactive insights into:

* Revenue Performance
* Product Category Analysis
* Geographic Sales Distribution
* Monthly Sales Trends
* Fulfillment Performance
* Top Revenue-Generating Products
